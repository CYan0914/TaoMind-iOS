## 一、先说结论：首篇为什么不能发「产品介绍」

你选的是**独立开发者人设**。人设号的敌人不是"没人看"，是**"看了记不住是谁"**。

小红书上的产品介绍笔记长这样：封面放 App 截图 + 大字「我做了个 App」，正文列功能点。这类笔记的数据通常停在 200-500 浏览，因为：
- 算法把它归到"工具/应用"流量池，池子小
- 读者划走时**记不住作者**，只记得"哦有个 App"
- 没有人设钩子，不会有人点关注

**人设号的正确第一篇 = 用一个所有人都想知道的数字 + 一个你亲口承认的失败，把"我是谁"钉进读者脑子里。**

TaoMind 恰好有一个极强的、真实的、反常识的故事核：

> **一个中国人，用《道德经》和《金刚经》做了个 App，卖给了欧美人。**
> **60 个用户，0 个付费。**

第一句是**文化反差**（钩子），第二句是**诚实到残忍的数字**（人设）。这两句的组合在小红书是稀缺的——满屏都是"我月入十万"，几乎没人敢发"我 0 付费"。

## 二、第一篇主题（选定）

### 主题：**我用《道德经》做了个 App 卖给老外，60 个用户，0 个人付费**

**为什么选它：**

| 维度 | 判断 |
|---|---|
| 转发力 | 「中国人用道德经赚老外的钱」——天然的身份反差，容易引发"中国人做文化输出"的转发 |
| 共鸣 | 「做了半天没人付费」——所有做过副业/独立开发/自媒体的人都懂，评论区会炸出同类 |
| 完读率 | 数字前置 + 失败坦承，读者想知道"后来呢" |
| 人设建立 | 同时立住"懂传统文化"+"真做产品"+"不装"三个标签 |

**备选（如果这篇数据不好，第 2-3 篇用）：**
- B 案：《被 App Store 拒审 3 次，理由离谱到我笑了》——纯踩坑，涨粉快但人设浅
- C 案：《我花了 X 天，把 500MB 的 App 压到 80MB》——技术流，吸引开发者但不吸引泛人群
- D 案：《道德经里哪一句最适合现代人？我把它做成了产品》——文化向，最安全但最平

**建议：首篇发 A 案。** 它同时有钩子和人设，是唯一能"一篇立住号"的选择。

> **关键决定（2026-09-30）**：用户**真机重拍干净截图**。上面的 App Store 营销图一律不用。
> **首图**：用小红书自带文字生图功能（用户定），不需要截图素材。

**真机截图拍摄清单（请按这个拍，中文界面优先）：**

1. **求取智慧页**（空状态）—— 中文界面，显示"描述你的处境，获取古老智慧的指引"
2. **智者之言的回答页** —— 这个最重要，要能看出"输入困境 → 经文回答"的效果
3. **经藏页** —— 显示 166 条 / 道德经 81 章的分类
4. **修行日志 + 连击天数** —— 打卡界面
5. **珍藏卡展示页** —— 若 app 内有卡片墙，拍一张

拍法：**直接手机截屏**（不要拍照，不要加框），原图发我，我来裁切排版。

### 图 1｜首图（决定 90% 的成败）

**做法（用户已定）：直接用小红书自带的「文字生图」。**

不走设计，走原生感——小红书文字卡片本身就是平台原生内容，算法不判广告，读者不设防。

**文字内容（照抄，不要加字）：**

```
我做了一个 App
把《道德经》卖给了老外
60 个用户，0 付费
```

排版建议：
- 选**米色/宣纸底**或**深色底**的模板，别用花哨图案
- 字号拉满，「60 个用户，0 付费」这行可以用不同颜色或加粗
- **不要放 App 图标、不要放手机**——放了就成了产品广告

> ⚠️ 第三行是全篇最强的一句，必须在首图上。不要藏进正文。

### 图 2｜反差图（决定完读率）

**素材来源（用户真机补拍）：** 同一页的中文版 + 英文版对照。

> 原计划用 `1.5.0` 的截图 —— 已核实**那是 App Store 营销图（英文 UI + 英文营销文案）**，不能用。
> 改为等用户真机拍：**中文系统一张 + 英文系统一张**（切系统语言，同一页面）。

图上文字：

```
同一个 App
中国人看到的 / 老外看到的
```

这一张是"文化输出"的视觉证据，转发时最常被截图。

**如果不想切系统语言**：退而求其次，用「中文界面截图 + 珍藏卡」并置，文案改成「它把这两样东西放进了同一个 App」。

### 图 3｜产品内核（决定"这 App 到底干嘛的"）

**用珍藏卡 + 真机截图组合。** 精选 3 张珍藏卡竖排 + 一张「智者之言」结果页。

素材：
- 珍藏卡：`Card\7_final.jpg`（"委屈保全"偏人生困境）、`Card\20_final.jpg`、`Card\46_final.jpg` —— **我可以直接做，不用等**
- App 回答页：**待真机补拍**

图上文字：

```

它用 2500 年前的智慧回答你
```

### 图 4｜真实数字（人设的锚点）

**这张不需要好看，需要真实。**

做一张"数据面板"风格的图：
- 60 用户 / 0 付费 / 开发 89 天 / 166 章经文 / 60 张珍藏卡 / 2 个评分 5.0

> ⚠️ **这些数字必须是真的。** 你告诉我实际数字我改。假的数字是这类笔记唯一的死因——评论区一定会有人追问细节，答不上来人设当场崩。

推荐格式：深色背景 + 白字，像后台截图的感觉（甚至可以真的截 RevenueCat / App Store Connect 后台，**打码敏感信息**）。真后台截图 > 设计过的数据图。

### 图 5｜踩坑/失败（决定"这人真实"）

**这张最重要，也最容易做砸。**

**已找到真实素材** —— `RESOLUTION_2_1b.md` 里记录了一次真实的 2.1(b) 拒审：

> 被拒理由：App 内购买项目"不易找到"（IAP not easily accessible）
> 真实根因：**Lifetime 买断挂在一个独立的 RevenueCat offering 里，而付费墙根本没读它**
> —— 也就是说，这个 IAP 对用户等于不存在

**这是个极好的失败故事**：不是"苹果刁难我"，是**我自己写了个 bug，导致一个付费项从来没人能买到**。诚实、具体、有技术细节、还顺手解释了为什么 0 付费。

素材方案（**这一张我来做，不用你提供图**）：
- 用小红书文字卡，写那段拒绝理由的英文原文 + 中文翻译
- 或做「真实根因」对比：`offering = "lifetime"` vs 代码里只读 `current offering`

图上文字：

```
苹果说我的 App 里
有个付费项没人找得到

查了两天才发现
它是真的找不到
我自己的 bug
```

> ⚠️ 这段和「0 付费」形成因果闭环——**不是没人买，是有个东西根本买不到**。这是全篇最有力的一击，也是人设的落点：一个会承认自己 bug 的开发者。
> ⚠️ **发布前请确认这段能公开**（拒审邮件内容公开一般无风险，但涉及 Apple 审核细节，你判断一下）。

### 图 6｜结尾（决定"关不关注"）

**素材：一张珍藏卡做底 + 文字。** 我可以直接做。

图上文字：

```
它现在国内也能下载了
免费，搜 TaoMind

下一篇：
我怎么发现有个付费项
从来没人能买到
```

> 「下一篇」预告是小红书涨粉的关键动作——它把"看完"变成"关注"。
> 预告用**悬念**而不是结论（"我怎么发现的"），比"我是怎么被拒绝的"更勾人。

## 四、正文文案（初稿）

> 字数控制在 800-1000 字。小红书长文笔记正文超过 1000 字折叠，关键信息要在前 3 行。

---

**正文：**

我做了个 App，叫 TaoMind。

它做的事很简单：你输入今天遇到的困境——团队快撑不住了、和父母又吵了一架、不知道该不该辞职——它用《道德经》和《金刚经》里的智慧回答你。

2500 年前的话，回答 2026 年的问题。

做它之前我以为自己想清楚了一件事：**这东西老外会喜欢。**

结果上线到现在，60 个用户，0 个人付费。

（不是卖惨。往下看。）

**为什么我觉得老外会喜欢**

我在 App 里放了三件事：


一是**「求取智慧」**。不是算命，不是塔罗。你写下真实的处境，它从经文里找出对应的一句，然后告诉你这句话对你今天意味着什么。有个人写"我团队快被截止日期压垮了"，它回的是一句——

> The soft overcomes the hard.
> 柔能胜刚。

下面还有一段解读，讲为什么硬扛反而会断。

二是**经藏**。道德经 81 章、金刚经全文、庄子精选，一共 166 条。每一条有原文、有白话、有反思。我做这个是因为市面上讲老庄的 App 要么太玄，要么太学术。

三是**修行日志**。每天读一章，写一句感悟，连续打卡。这个功能后来变成了留存最高的一块——老外对这个"每日功课"的执念比我想的深得多。

**然后我发现了一件没预料到的事**

上线后我一直在看后台，有个感觉越来越明显：

**中文用户，比英文用户更愿意认真读。**

不是人数——中文用户本来少。是完成度。老外点进来是好奇，划两下就走了；中文用户会真的从头读到尾，会写感悟，会连续打卡。

我一开始没想明白。后来意识到：对中国人来说，这些话是**熟悉但没细想过**的——"上善若水"谁都会背，但没人真的用它做决定。

对老外来说，这些话是**完全陌生的新东西**，他们更容易停在"哦，有趣"，但不容易真的用起来。

所以这个 App 对两拨人的价值其实是不一样的：
- 对老外，它是新知识
- 对中国人，它是**重新学会用老祖宗的话解决今天的问题**

这一点是我做之前完全没想到的。

**0 付费这件事**

我复盘了很久。

功能我加了一堆——语音输入、名师点评、月报、珍藏卡。但用户为什么要为它付钱？我答不上来。

**然后我发现了一件很蠢的事。**

苹果有一次拒绝了我，理由是"App 内购买项目不易找到"。

我当时觉得挺冤，我明明做了付费墙。查了两天才发现——

**有一个终身买断的选项，挂在了一个 app 根本没读取的地方。**

也就是说：这个商品，从上线那天起，**没有任何一个用户能看到它，更别说买它。**

我一直以为"0 付费"是因为用户不想花钱。

其实有一部分原因，是**有个东西根本买不到。**

这个 bug 我修了。但我想说的是另一件事：

我花了很久才承认——我一直在做"更好的产品"，但没有做"更让人想买的产品"。这两个是完全不同的事。

**最后**

它现在国内 App Store 也能下载了，免费，搜 TaoMind 就有。

如果你搜不到，评论区告诉我，我看看是哪里出问题了。

## 七、我要提醒你的两个风险

1. **「0 付费」是双刃剑。** 它极其真实、极其立人设，但如果后续你一直没解决付费问题，读者会从"共鸣"转为"这人不行"。所以这篇之后，**第 2-3 篇必须给出"我做了什么改动"**，形成叙事弧。别让失败变成终点。

2. **这个号如果只讲 TaoMind，天花板很低。** TaoMind 是个小众品类。人设号的长线打法是：**TaoMind 作为"我的作品"出现，但内容主线是"独立开发这件事本身"**——怎么选题、怎么被拒、怎么定价、怎么面对 0 付费。这样受众从"对道德经感兴趣的人"扩展到"对做产品感兴趣的人"，差了至少一个数量级。
